# Unit 401 Programming — Sample Syllabus (Level 4)

## Learning Outcomes

LO1: Analyse a simple problem and produce a structured program design using appropriate control flow.

LO2: Implement a working solution in a high-level language, applying modular design and meaningful naming.

LO3: Test the solution against stated requirements and discuss limitations.

## Core Topics

- Variables, data types, and operators
- Selection and iteration
- Functions and parameter passing
- File input and output
- Introductory testing and debugging

## Unit 401: Assessment brief

Students submit a short programming assignment that demonstrates the learning outcomes above.
Work that does not address programming fundamentals for this unit should be flagged as out of syllabus.
